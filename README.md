# Ammar Ali | Professional Portfolio

Static portfolio for GitHub Pages. Upload the contents of this folder to the repository root. Keep `index.html`, `styles.css`, `script.js`, `assets/` and `Ammar_Ali_Professional_CV.pdf` together. Enable GitHub Pages for the publishing branch. The PDF button uses the included resume.

Features: light/dark theme, work-category filters, search, accessible detail dialogs, mouse spotlight and responsive navigation. Project-based experience is presented by discipline, without client project codenames. No private financial or identity records are included.
